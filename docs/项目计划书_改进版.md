## 一、研究背景与问题提出

### 1.1 研究背景

心理健康问题已成为全球性公共卫生挑战。世界卫生组织（WHO）数据显示，全球约有10亿人受到精神健康问题影响，而心理健康服务的供给严重不足，特别是在资源有限的地区。传统的压力与情绪评估主要依赖主观问卷量表（如PSS-10、STAI等），这些方法虽然经过临床验证，但存在即时性差、回溯偏差、无法连续监测等固有局限。随着可穿戴设备的普及，一种全新的可能性正在浮现：通过日常佩戴的智能手表、手环等设备持续采集生理信号，实现压力与情感状态的客观、连续、无创监测。

可穿戴设备内置的传感器（PPG、EDA、加速度计等）能够在不影响用户日常活动的前提下，24小时不间断地记录生理数据。PPG（光电容积脉搏波）信号通过LED光源照射皮肤并检测反射光强变化来间接测量血容积变化，可从中提取心率、心率变异性（HRV）等重要心血管指标。EDA（皮肤电活动）信号则通过测量皮肤表面两点间的电导率变化来反映交感神经系统的激活程度，是情感唤醒和认知负荷的敏感指标。这两种信号的组合为情感状态推断提供了互补的信息维度：PPG主要反映心血管系统的副交感神经调控状态，EDA则直接映射交感神经兴奋程度。

### 1.2 研究动机

尽管多模态生理信号情感计算领域已有大量研究，但面向可穿戴设备实际部署的轻量级方法仍然面临以下挑战：

**挑战一：计算资源约束与模型复杂度的矛盾。** 现有研究多采用深层网络（如ResNet-50、Transformer）或复杂的特征工程流程，这些方法虽然在实验室条件下取得了优异性能，但参数量动辄数百万乃至上亿，难以部署到资源受限的可穿戴设备（如Apple Watch、华为手环）上。消费级可穿戴设备的处理器通常仅有有限的内存和算力，对模型的体积和推理速度有严格限制。因此，如何在保持较高分类精度的同时大幅压缩模型规模，是一个亟待解决的实际问题。

**挑战二：个体差异性导致模型泛化能力不足。** 生理信号具有显著的个体差异性和时间变异性。同一被试在不同时间、不同身体状态下的生理基线水平可能截然不同，不同被试间的差异则更为显著。许多现有研究采用传统的随机划分训练/测试集方式，即将同一被试的数据同时用于训练和测试，这种方式会导致对模型泛化能力的高估——模型可能通过记忆被试特异性的生理模式而非学习情感相关的通用特征来实现"高准确率"。可穿戴设备的实际应用场景要求模型能够适应新用户而无需重新训练，这对模型的被试独立泛化能力提出了更高要求。

**挑战三：多模态融合策略的有效性尚未得到充分验证。** 虽然多模态融合在理论上可以提供更丰富的信息，但PPG与EDA两种信号在采样率（64Hz vs 4Hz）、信号形态、物理含义等方面差异显著，如何设计有效的融合策略以发挥两种模态的互补优势而非相互干扰，仍是一个开放性问题。早期融合、晚期融合、混合融合等多种策略各有优劣，需要系统性的对比实验来验证。

### 1.3 研究问题

基于上述背景与动机，本研究围绕以下核心问题展开：

**核心研究问题**：面向可穿戴设备资源约束场景，如何设计一种轻量级的多模态深度学习方法，利用PPG与EDA信号实现高精度的情感状态检测，并具备良好的被试独立泛化能力？

由此引申出三个子问题：

- RQ1：浅层1D-CNN架构能否在参数量仅3-5万的约束下，达到与深层网络相媲美的三分类性能？
- RQ2：PPG与EDA的特征级融合策略相比单模态和各模态独立预测后融合，能否显著提升分类性能？
- RQ3：留一被试交叉验证（LOSO）评估框架下，模型的被试独立泛化性能能否达到可穿戴实际应用的可用水平？

## 二、国内外研究现状与分析

### 2.1 单模态PPG情感识别研究

PPG信号因其可从消费级可穿戴设备便捷获取的特点，已成为情感计算领域的研究热点。在压力检测方向，Ali等（2025）提出了一种浅层深度学习模型，仅使用PPG信号即在WESAD数据集上取得了优异的压力监测性能，证明了浅层网络在生理信号分析中的可行性。Nguyen等（2026）提出了SPERC（Separable CNN for PPG-based Emotion Recognition），采用可分离卷积进一步压缩参数量，在PPG情绪识别任务中达到了新的性能水平。Kim等（2026）的Pulse2stress框架则结合了HRV特征提取与堆叠LSTM，从PPG中挖掘时序动态信息。

然而，上述研究大多聚焦于单模态分析，未能充分利用可穿戴设备多传感器的数据互补性。此外，部分研究采用的被试依赖评估方案可能高估了模型的实际泛化性能。

### 2.2 多模态生理信号融合研究

多模态融合被认为是提升情感识别鲁棒性的有效途径。Cai等（2024）提出了CNN-MLP轻量级架构，通过多特征融合策略结合PPG、EDA等多种生理信号，在WESAD上取得了显著优于单模态的性能。Ko等（2024）采用自适应优化与迁移学习策略进行多模态生理信号分类，验证了自适应加权融合的有效性。Zhao等（2025）利用神经架构搜索（NAS）自动发现多模态生理信号的最优融合结构。

尽管这些方法在实验室条件下取得了良好效果，但普遍面临模型复杂度高、计算开销大的问题，距离实际可穿戴部署仍有距离。

### 2.3 轻量级深度学习模型研究

近年来，模型轻量化成为深度学习研究的重要方向。在生理信号分析领域，Khosravi等（2024）提出了基于轻量深度神经网络的PPG信号质量评估方法，为低质量信号片段的自动剔除提供了技术支撑。Fan等（2026）提出的CEM-Net（CNN-ECA-Mamba Network）结合了注意力机制与状态空间模型，在PPG压力检测中取得了良好性能。Calza Metre（2025）的系统综述全面总结了可穿戴传感器数据机器学习压力检测的最新进展。

上述研究表明，学术界正在积极寻求"轻量"与"高性能"之间的平衡点，但面向三分类情感状态检测（基线/压力/娱乐）且严格采用被试独立评估的轻量级多模态融合方法研究仍相对匮乏，这正是本研究拟填补的空白。

### 2.4 现有研究的不足与本研究的切入点

综合分析现有研究，主要存在以下不足：

| 不足 | 本研究的应对策略 |
|------|-----------------|
| 模型复杂度高，难以部署到可穿戴设备 | 设计参数量仅3-5万的浅层1D-CNN |
| 评估方案存在被试泄露，泛化性能被高估 | 严格采用LOSO留一被试交叉验证 |
| 多模态融合策略缺乏系统性对比 | 对比单模态、晚期融合与特征级融合三种方案 |
| 缺乏信号质量保障机制 | 引入SQI信号质量指数进行数据清洗 |
| 研究止步于分类准确率，缺乏应用形态展示 | 构建前端可视化系统，展示落地应用形态 |

## 三、研究目标与科学假设

### 3.1 研究目标

本研究旨在设计并实现一种面向可穿戴设备资源约束场景的轻量级多模态深度学习方法，利用PPG与EDA信号实现三种情感状态（基线、压力、娱乐）的高精度自动检测。具体目标包括：

1. **数据预处理与质量保障**：建立完整的PPG+EDA信号预处理链路，包括带通滤波、工频干扰抑制、信号质量评估与数据标准化，确保输入数据的高质量与可靠性。

2. **多维度信号分析**：从时域（PPG形态学特征+HRV指标）、频域（FFT功率谱+LF/HF比值）和时频域（STFT时频图）三个维度系统分析不同情感状态下生理信号的差异化特征规律。

3. **轻量级多模态深度学习模型**：设计参数量约3-5万的双分支1D-CNN架构，采用特征级融合策略联合PPG与EDA信号进行分类，在严格LOSO评估框架下实现被试独立的高精度情感状态检测。

4. **前端可视化展示系统**：构建医学影像风格的可交互式前端展示界面，直观呈现信号处理全流程与模型推理结果，体现研究的可穿戴健康监测落地应用形态。

### 3.2 科学假设

本研究提出以下可验证的科学假设：

**H1**：在参数量仅3-5万的约束下，双分支1D-CNN能够在WESAD数据集的三分类任务上达到不低于85%的整体准确率。

**H2**：PPG+EDA特征级融合的分类性能显著优于任一单模态（PPG或EDA单独使用），也优于各模态独立预测后的晚期融合策略。

**H3**：经过SQI信号质量筛选的数据训练得到的模型，其LOSO泛化性能显著高于未经筛选的数据训练的模型，验证了信号质量控制在提升被试独立泛化能力中的关键作用。

## 四、研究意义与创新点

### 4.1 理论意义

本研究的理论意义主要体现在以下三个方面：

第一，**验证浅层网络在生理信号分析中的有效性边界**。当前深度学习领域存在"越深层越好"的偏见，本研究通过系统的对比实验，探索轻量级架构在多模态生理信号情感计算中的性能上限，为资源约束场景下的模型设计提供理论依据。

第二，**揭示PPG与EDA信号在情感状态推断中的互补机制**。通过对比单模态与多模态融合的性能差异，并可视化各模态卷积分支学习到的特征表示，深入理解两种生理信号在情感识别中的信息互补模式。

第三，**建立被试独立评估的基准结果**。现有研究采用的评估方案参差不齐，本研究严格采用LOSO交叉验证，为后续研究提供公平、可靠的性能对标基准。

### 4.2 应用价值

本研究的应用价值体现在可穿戴健康监测领域的实际落地潜力：

第一，**模型可直接部署到消费级可穿戴设备**。3-5万参数的轻量级架构在ARM Cortex-M系列微控制器或可穿戴SoC上即可实现实时推理，无需云端辅助，保护用户隐私。

第二，**前端可视化系统展示了完整的落地应用形态**。医学影像风格的可交互界面不仅提升了提交的视觉冲击力，更直观地展示了从信号采集到情感状态显示的完整数据流，体现了研究的工程化思维。

第三，**研究成果可作为智能健康管理系统的核心模块**。将情感状态检测与运动监测、睡眠分析等功能集成，可构建全方位的个人健康管理系统，具有良好的商业转化前景。

### 4.3 创新点

本研究的主要创新点包括：

1. **轻量级双分支架构设计**：首次在WESAD三分类任务上系统评估参数量仅3-5万的双分支1D-CNN，探索了资源约束场景下的性能-效率最优平衡。

2. **信号质量驱动的数据清洗**：引入SQI信号质量指数对训练数据进行预筛选，有效去除运动伪影等低质量片段，提升模型的泛化鲁棒性。

3. **前端可视化落地形态**：构建了医学影像风格的可交互展示系统，将研究成果从"论文中的图表"转化为"可体验的原型系统"，体现了完整的工程化思维。

## 五、数据集介绍

### 5.1 WESAD数据集

WESAD（Wearable Stress and Affect Detection）数据集由德国班贝格大学和奥格斯堡大学的研究团队于2018年发布，是生理信号情感计算领域最具代表性的公开数据集之一。

| 属性 | 说明 |
|------|------|
| 被试人数 | 15人（12男3女），年龄25.8±4.0岁 |
| 信号类型 | PPG(64Hz)、ECG(700Hz)、EDA(4Hz)、TEMP、RESP、EMG、加速度计 |
| 情感状态 | 基线(Baseline)、压力(Stress)、娱乐(Amusement) |
| 记录时长 | 约60分钟/被试 |
| 设备 | RespiBAN Pro（胸带）+ Empatica E4（手腕） |
| 数据格式 | Python pickle (.pkl) |
| 获取方式 | 官网免费下载（需签署使用协议） |

### 5.2 数据说明

本项目主要使用WESAD数据集中的PPG和EDA两种信号。PPG信号以64Hz采样，反映心脏搏动引起的血管容积变化。EDA信号以4Hz采样，反映交感神经系统的激活程度。

数据集包含三种标注条件：
- **基线（Baseline）**：被试静息放松状态，持续约5分钟
- **压力（Stress）**：通过特里尔社会压力测试（TSST）诱导，持续约10分钟
- **娱乐（Amusement）**：观看幽默视频片段，持续约5分钟

## 六、技术路线与实施方案

### 6.1 整体技术路线

```
数据加载 → 预处理（滤波/去噪/SQI/标准化） → 信号分段
                                              ↓
时域分析（形态学特征+HRV） ──┐
                              ├──→ 特征级融合 → 1D-CNN → 分类结果
频域分析（FFT+LF/HF） ──────┘    （双分支架构）
                              ↑
时频分析（STFT时频图） ──────┘
                              ↓
                        前端可视化展示系统
```

### 6.2 数据预处理方案

**第一步：带通滤波**
- PPG：Chebyshev II型带通滤波器，0.5–8 Hz
- EDA：低通滤波器，截止频率1 Hz

**第二步：工频干扰抑制**
- 二阶IIR陷波滤波器（notch filter），Q=35，针对50Hz

**第三步：信号质量评估（SQI）**
- 基于波形模板匹配，剔除低质量片段

**第四步：Z-score标准化**
- 使均值为0、标准差为1

**第五步：信号分段**
- 片段长度10秒（PPG: 640点，EDA: 40点），步长5秒

### 6.3 传统信号分析方法

**时域分析**：脉搏波检测（收缩峰、舒张峰、重搏切迹），提取HRV指标（SDNN、RMSSD）

**频域分析**：FFT功率谱，计算VLF/LF/HF频带能量及LF/HF比值

**时频分析**：STFT短时傅里叶变换，Hanning窗，256点窗长，128点重叠

### 6.4 深度学习模型设计

| 层 | 配置 | 输出尺寸 |
|----|------|----------|
| 输入层 | PPG(640,1) + EDA(40,1) | 640x1 / 40x1 |
| Conv Block 1 | Conv1D 32@3 + ELU + BN + MaxPool(2) | 320x32 |
| Conv Block 2 | Conv1D 64@3 + ELU + BN + MaxPool(2) | 160x64 |
| Conv Block 3 | Conv1D 128@3 + ELU + BN + MaxPool(2) | 80x128 |
| Conv Block 4 | Conv1D 128@3 + ELU + BN + MaxPool(2) | 40x128 |
| 全局平均池化 | GlobalAvgPool1D | 128 |
| 全连接层 | Dense(128) + Dropout(0.3) + ELU | 128 |
| 输出层 | Dense(3) + Softmax | 3 |
| **总参数量** | **约3-5万（轻量级）** | - |

### 6.5 多模态融合策略

采用**特征级融合（Feature-level Early Fusion）**：PPG和EDA卷积分支各自经过卷积、池化和全局平均池化后，将两个128维特征向量拼接为256维向量，输入共享全连接层。

### 7.1 设计目标

为增强提交的视觉冲击力并展示研究的落地应用形态，本项目将构建一个**医学影像风格的可交互生理信号监测与情感分析展示系统**。该系统采用暗色主题（Dark Mode），模拟ICU医疗监护仪的界面风格，将信号处理的全流程以可视化的方式呈现。
