# 前端可视化验证系统 · 网页说明

> 本文档为论文"6.1 前端可视化验证系统"小节的编辑参考，逐面板说明展示内容、数据来源与交互。访问方式：`cd frontend && npm run dev` → 浏览器打开 http://localhost:5173

---

## 一、系统定位与架构

| 项目 | 说明 |
|------|------|
| 定位 | WESAD 三分类情感状态检测的**研究成果验证看板**，非实时监测系统 |
| 风格 | 医学监护仪风格（亮色主题，模拟 ICU 多参数显示） |
| 技术栈 | React 19 + TypeScript + Vite 7 + ECharts 6 + Tailwind CSS 3 + shadcn/ui |
| 架构 | **纯静态预计算**：Python 流水线一次性导出 JSON，前端 fetch 读取，无后端服务 |
| 部署 | 可直接 GitHub Pages 静态部署 |
| 切换延迟 | 被试/状态切换约 50 ms（仅 fetch 小 JSON） |

**为何不做实时后端**：WESAD 是固定数据集，数据永不变；实时计算每被试需加载约 900 MB 的 pkl（约 3 s）且需加载训练好的 fold 模型，对静态数据毫无收益，徒增 Flask 进程与 CORS 复杂度。预计算 + 静态服务是最合理架构。

## 二、数据契约（JSON 接口）

### 全局文件（`public/data/*.json`，研究级聚合，不随被试切换）

| 文件 | 内容 | 关键数值 |
|------|------|----------|
| `model_metrics.json` | 整体性能 | accuracy **0.7494**, macro_F1 **0.7171**, params **21,627**, size **0.083 MB**；逐类 F1：基线 0.777 / 压力 0.877 / 娱乐 0.497 |
| `confusion_matrix.json` | LOSO 聚合混淆矩阵 | `[[2507,186,807],[95,1736,134],[352,70,673]]` |
| `hrv_features.json` | HRV 四特征箱线图（15 被试 ECG） | 见下表 |
| `training_curves.json` | 代表性折（S15）训练曲线 | 含 fold_id、val_source 说明 |
| `ablation_comparison.json` | H2 消融 + Wilcoxon | 见下表 |

### 被试文件（`public/data/subjects/S{X}.json`，被试级，切换时刷新）

每被试一个打包文件，含三状态（baseline/stress/amusement）的干净段：
```
states.{baseline|stress|amusement}.{signal_ppg, signal_eda, spectrum, spectrogram}
recall         逐类检出率（从该被试 LOSO 混淆矩阵派生）
prediction     全窗口预测分布
loso           该被试个人准确率/macro_F1
```

## 三、界面布局（逐面板说明）

### 顶部导航栏
- **标题**：可穿戴情感状态监测系统 | WESAD Dataset 徽标
- **被试下拉框**：S2–S17（15 人，无 S12），切换触发 fetch 对应被试 JSON
- **状态按钮组**：[基线][压力][娱乐]，切换查看该被试对应状态段的波形/频谱/时频（无干净段则禁用）
- **个人 LOSO 准确率**：当前被试作为测试折时的准确率（如 S15 = 97.5%、S4 = 80.7%）

### 第一行：状态概览（4 卡片）
| 卡片 | 内容 | 数据源 | 级别 |
|------|------|--------|------|
| **当前查看状态** | 大字显示选中状态（基线/压力/娱乐）+ 三类 recall 条形图（压力/基线/娱乐，高亮当前） | 被试文件 `recall` | 被试级 |
| 信号质量 SQI | "优"（excellent）+ 进度条 | 静态 | 固定 |
| 模型准确率 | **74.9%** + macro-F1 **71.0%** | `model_metrics.json` | 研究级 |
| 模型规模 | **21,627** 参数 / **0.083 MB** | `model_metrics.json` | 研究级 |

> **重要提示**（避免论文误述）：第一张卡的"当前查看状态"是**用户主动选择查看的状态段的真实标签**，不是模型对被试的"当前判定"。WESAD 每个被试依次经历基线→压力→娱乐三阶段，给整段录音贴单一"当前状态"无意义；早期版本曾用"预测最多的类"作为当前状态，但因基线窗口数最多（~52%）导致几乎所有被试都显示"基线"，是类别不平衡的算术产物，已弃用。

### 第二行：双通道波形（被试级，随状态切换）
- **PPG 波形**：选中被试 + 状态段的 10 s（640 点 @ 64 Hz），z-scored
- **EDA 波形**：同段 10 s（40 点 @ 4 Hz），z-scored

### 第三行：频域 + 时频（被试级，随状态切换）
- **FFT 功率谱**：该状态段 30 s 的 PPG 单边功率谱，VLF/LF/HF 三频带分色标注
- **STFT 时频热力图**：该状态段 60 s 的时频谱（Hanning 窗、256 点、192 重叠）

### 第四行：统计图（研究级，固定）
- **LOSO 聚合混淆矩阵**：15 折聚合（见表），蓝白热力图
- **HRV 特征分布**：15 被试 ECG 的四特征箱线图（SDNN/RMSSD/LF-HF/HR_mean × 三状态）

| 特征 | 基线 | 压力 | 娱乐 |
|------|---:|---:|---:|
| SDNN (ms) | 59.9 | 46.0 | 63.7 |
| RMSSD (ms) | 41.7 | 28.2 | 41.7 |
| LF/HF | 2.1 | 2.6 | 2.9 |
| HR_mean (bpm) | 71.3 | 93.3 | 71.6 |

### 第五行：训练 + 预测 + 指标（混合级）
- **训练曲线**（研究级）：代表性折 S15 的逐 epoch 训练/验证 loss 与准确率；注明验证集为"训练窗口 8:2 随机划分，测试被试不参与 early stopping"
- **预测分布**（被试级）：当前被试全窗口的预测类别占比（基线/压力/娱乐）
- **分类性能指标**（研究级）：三类 F1 条形图（基线 0.777 / 压力 0.877 / 娱乐 0.497）

### 第六行：H2 消融（研究级，固定）
- **消融柱状图**：四变体准确率 + macro F1（误差棒），Dual 柱顶标注 ★p=0.001

| 变体 | 准确率 | macro F1 | 参数量 |
|------|---:|---:|---:|
| **Dual** | **0.749** | **0.710** | 21,627 |
| Late | 0.680 | 0.665 | 16,006 |
| EDA | 0.668 | 0.656 | 3,115 |
| PPG | 0.586 | 0.530 | 18,771 |

- **Wilcoxon 卡片**：Dual vs PPG p=0.001（显著 **）、vs EDA p=0.104（ns）、vs Late p=0.138（ns）+ 一句 EDA 参数效率说明

### 底部信息栏

## 四、交互说明

1. **切换被试**：下拉框选 S2–S17 → 波形/频谱/时频/预测分布/逐类 recall/个人准确率全部刷新为该被试；聚合面板（混淆矩阵/HRV/训练曲线/消融）不动。
2. **切换状态**：点 [基线][压力][娱乐] → 波形/FFT/STFT 切换为该被试对应状态段；recall 条高亮当前状态。
3. **代表性被试点位**（论文可举例）：
   - **S15**：个人 acc 97.5%，三态 recall 都高（压力 100%/基线 98%/娱乐 91%），最佳被试
   - **S4**：娱乐 recall = 0（娱乐段完全漏检），基线 recall 99.6%
   - **S17**：娱乐 recall 95.9% 但压力 recall 仅 58.7%（反向模式）
   - **S2**：压力 recall 96.7%、娱乐 56.3%，主力示例被试

## 五、数据流小结（论文可用一句话概括）

> Python 流水线完成 WESAD 预处理、LOSO 训练与 HRV/FFT/STFT 分析后，将结果导出为 11 个全局 JSON 与 15 个被试 JSON；前端 React 组件按数据契约 fetch 并以 ECharts 渲染，被试级面板随用户切换实时刷新，研究级聚合面板保持固定，实现"成果验证 + 被试探索"双形态。
