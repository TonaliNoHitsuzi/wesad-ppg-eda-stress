## 第一部分 课程论文任务书

### 一、考核形式

本课程期末考核采用"公开数据集独立分析课程论文"的形式进行。每位学生须围绕生物医学信号处理相关主题，自主选择一个公开数据集，独立完成数据获取、数据预处理、特征提取、数据分析、可视化展示、结果讨论与课程论文撰写的全过程。

严禁直接复现网络教程，或使用他人已完成的完整代码与报告。教师将结合代码运行记录、数据处理细节与论文写作内容综合判断独立完成情况。

### 二、论文选题范围

选题应与生物医学工程中的信号采集、处理或分析相关，鼓励结合自身专业方向选择感兴趣的信号类型。以下选题方向及推荐数据集供参考，学生也可在与教师沟通后选择其他公开数据集。

#### 2.1 脑电 EEG

可选方向包括：α/β波分析、睡眠阶段分析、情绪识别、癫痫检测等。

推荐数据集：PhysioNet EEG、Sleep-EDF、CHB-MIT。

#### 2.2 心电 ECG

可选方向包括：心率变异性（HRV）分析、心拍分类、心律失常检测、功率谱分析等。

推荐数据集：MIT-BIH Arrhythmia Database、PTB Diagnostic ECG Database。

#### 2.3 肌电 EMG

可选方向包括：肌肉疲劳分析、动作识别、信号包络提取等。

推荐数据集：Ninapro DB。

#### 2.4 医学图像或多模态生理信号（鼓励方向）

可选方向包括：fNIRS、PPG、呼吸信号，以及多通道同步生理信号的联合分析等，此方向在评分中将给予创新性加分。

### 三、论文基本要求

#### 3.1 独立完成

每位学生必须独立完成数据处理、程序编写、图表绘制与论文撰写，严禁抄袭、代做或组队共用代码。一经发现学术不端行为，按本任务书第七部分处理。

#### 3.2 必须包含的技术内容

**（1）数据预处理**

至少应包含以下处理中的若干项，并在论文中说明所用方法的原理、参数设置与实现代码：

- 滤波（低通/高通/带通等）
- 去噪
- 去基线漂移
- 工频干扰（50/60 Hz）抑制
- 数据标准化

**（2）至少两种分析方法**

不得仅使用单一分析方法，应至少综合运用以下两种及以上方法：

- 时域分析
- 频域分析（FFT）
- 时频分析（STFT / CWT）
- 小波分析
- 特征统计分析

**（3）特征提取**

需提取至少一种具有生物医学意义的特征，例如：

- HRV相关指标（如SDNN、RMSSD等）
- α/β波能量
- 峰值频率
- RMS（均方根值）
- 肌电信号包络
- 时频能量分布

**（4）数据可视化**

论文中必须包含以下类型的图表，且总图表数量不少于8幅：

- 原始波形图
- 处理后波形图
- 频谱图或时频图
- 统计图

所有图表必须包含标题、坐标轴标签、单位及图例（如适用）。

#### 3.3 代码要求

必须提交完整、可运行且包含注释的代码，文件结构清晰。支持Python、MATLAB或LabVIEW，鼓励使用GitHub或Gitee进行版本管理（如使用，请在论文附录中附上仓库链接）。

## 第二部分 课程论文完成指南（详细教程）

### 第一步：选题与数据获取

1）结合自身兴趣与专业方向，从EEG、ECG、EMG或多模态信号中选择一个大方向，再细化到具体分析任务。

2）访问PhysioNet官网（physionet.org），按页面说明下载数据文件。

3）记录数据集的基本信息：采样率、通道数、记录时长、标注方式等。

4）建议先下载1-3条记录用于代码调试。

### 第二步：环境搭建

推荐使用Anaconda管理Python环境：

```bash
conda create -n biosignal python=3.10
conda activate biosignal
pip install numpy scipy matplotlib pandas
pip install mne          # 脑电/生理信号处理
pip install wfdb         # 读取PhysioNet格式数据
pip install PyWavelets   # 小波分析
```

### 第三步：数据读取与预处理

以MIT-BIH心电数据为例，使用wfdb库读取记录，并完成带通滤波与基线漂移去除。

### 第四步：时域、频域与时频分析

本课程要求至少使用两种分析方法。

### 第五步：特征提取

以ECG的HRV分析为例，需先从滤波后的信号中检测R波峰，计算RR间期序列。

### 第六步：数据可视化

使用Matplotlib绘制图表，确保每幅图均包含标题、坐标轴标签与图例。

### 第七步：论文撰写

建议按以下要点逐章撰写，全文不少于3000字。

### 第八步：参考文献检索与引用格式

参考文献检索建议优先使用：中国知网（CNKI）、万方数据、Google Scholar、PubMed、IEEE Xplore。

### 第九步：代码整理与提交打包

提交前请逐项自查代码可运行性、注释完整性、图表对应关系等。
